# 寻找设备资源

1. 用 list_hosts 确定机器范围和真实 host_id。界面限制的机器范围不可扩大。
2. 用 search_fleet，scope="resources"，传用户要求的 kind、count、min_free_gib、idle 等筛选字段。要求当前状态时传 refresh=true。
3. 同一台机器、同一种设备的卡数必须同时满足；不能跨机器凑卡。多芯片 NPU 的设备数不能直接当作物理卡数。
4. 继承上一轮条件时只传用户修改的字段；切换 scope 会重置旧条件。具体参数以工具 schema 为准。
5. 用 get_resources 复核候选机器。检查采样时间、状态和 coverage；未知、采集失败和过期均不能视为空闲。
6. 告诉用户实际候选、条件和未查清部分。无匹配时解释缺少的设备或显存，不擅自降低要求。

查询不会锁定或预留设备。预约和启动训练应在软件相应界面操作，不声称已经预约或启动。
