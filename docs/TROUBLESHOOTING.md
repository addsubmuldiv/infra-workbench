# 故障排查

先确认正在使用安装包还是源码、软件版本、出错机器和最后一次采样时间。不要为排障直接删除数据或终止未知进程。更多操作入口见 [文档目录](README.md)。

## 安装与启动

| 现象 | 先检查什么 | 后续说明 |
| --- | --- | --- |
| 缺少 Python 或依赖 | 安装包包含后台；只有源码方式需要准备 Python。确认下载的是安装包还是仓库 ZIP | [Windows 安装](WINDOWS.md) |
| 找不到 SSH | 在 PowerShell 执行 `ssh -V`；缺失时安装 Windows OpenSSH 客户端 | [Windows 常见问题](WINDOWS.md#常见问题) |
| 网页打不开、端口冲突 | 尝试本机地址 `http://127.0.0.1:8765/`；非默认端口使用实际地址。保留错误，确认端口占用者再处理 | [启动排障](WINDOWS.md#常见问题) |
| 更新后仍像旧版本 | 仅刷新页面不会重启后台；先保存编辑、处理终端任务，再从原入口正常退出后台并重新启动 | [更新与修复](WINDOWS.md#更新与修复) |

源码启动错误可检查数据目录的 `launch.log` 和 `desktop.log`。报告问题时只提供相关片段，先去除账号、主机地址和凭据。

## SSH 与资源采集

| 现象 | 建议检查 |
| --- | --- |
| SSH 连接失败 | 用同一台电脑上的 Windows 原生 `ssh 别名` 检查；确认账号、端口、密钥和跳板配置。WSL 或其他终端的密钥库不一定相同 |
| 主机指纹未知或变化 | 先向管理员核实身份；按 [连接说明](WINDOWS.md#安装与日常启动) 信任正确指纹，不要直接绕过校验 |
| SSH 能连，设备仍未知 | 在远端确认 Python 3 和对应 `nvidia-smi` / `npu-smi` 可用；检查页面采集错误及采样时间。连接成功不代表驱动采集成功 |
| 进程目录、命令不可见 | 检查远端账号的读取权限；需要时按机器配置 sudo 采集。它不会让网页终端或文件管理自动变成 root |
| 空闲数不符合预期 | 检查利用率、可见进程、剩余显存和采样时间；未知或过期不能算空闲。设备数与物理卡数也可能不同 |

详见 [资源与进程](GUIDE.md#查看资源与占卡进程)、[sudo 采集](GUIDE.md#按机器设置-sudo) 和 [批量导入](IMPORT.md)。

## AI 助手

1. 先确认使用 [模型接口](AGENT.md) 还是 [本机 CLI](EXTERNAL-AGENTS.md)；两者的登录和密钥不互通。
2. 模型接口先保存再测试连接。当前内置模型接口要求 Responses；地址、模型 ID、认证错误应分别核对。获取到模型列表不代表每个模型都有调用权限。
3. 文本测试通过但任务失败时，展开工具记录：服务还需要支持工具调用，并且对应机器必须可连接。区分模型请求错误和业务工具错误。
4. 找不到 CLI 时先检查本机安装和登录；被检测到程序不代表账号和网络可用。Codex 的单独说明见 [CODEX.md](CODEX.md)。

执行目标不符合预期时，检查输入区的「仅允许操作所选的机器」设置；左侧选中机器本身不会限制助手范围。结果不确定时先查询实际状态，取消不会回滚已经完成的操作。

## 预约与通知

- 一直等待：检查设备是否真的满足条件、采样是否新鲜；连接失败或状态未知会打断持续确认。后台重启后重新计时。
- 条件已满足却没看到通知：在预约记录分别检查条件状态和通知投递状态。保持托盘运行，并检查系统通知设置；“已提交”不等于通知已显示或阅读。
- 没收到邮件：先保存邮箱设置并发送测试邮件，到收件箱和垃圾邮件确认；还需为具体预约勾选邮件通知。SMTP 接受不等于送达。

详见 [预约状态](RESERVATIONS.md#如何看通知状态)、[邮件设置](MAIL.md) 和 [后台与通知](BACKGROUND.md)。

## 远程服务与文件

- 隧道已连接但页面打不开：先确认远端应用已经启动、端口正确；隧道状态不代表应用健康。见 [远程服务](PORT-FORWARDING.md)。
- VS Code 已打开但未连接：VS Code 独立完成 SSH 认证，工作台不传递保存的密码。见 [SSH 隧道与 VS Code](SSH-TUNNELS.md#从工作台打开-vs-code)。
- 文件保存或传输中断：先刷新目标目录核对实际结果，再决定重试；文件管理使用 SSH 账号权限，不使用 sudo。见 [文件权限与限制](FILES.md#权限与传输限制)。

仍无法解决时，报告软件版本、系统、运行方式、复现步骤、预期与实际结果及脱敏错误。不要提交数据库、`data`、完整 SSH 配置或模型密钥。
