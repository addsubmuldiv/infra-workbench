# 资源历史

在左侧选择「资源历史」，或从机器卡片、集群菜单进入。选择机器范围、日期、时区和 GPU/NPU 类型，即可回看当日空闲设备数量。

## 图表与统计

- 单机数量图显示各时段空闲多少个设备。
- 多机图按时间显示整机空闲、部分设备空闲、无空闲设备、数据未知各几台。四类互斥，合计等于选择的机器数。
- 热力图每行一台机器，每格标出该时段的空闲设备数。统一绝对数量色阶，半透明底、细边框、小圆角；未知用独立斜纹和问号表示。
- 顶部显示全部设备空闲时长、已确认空闲设备小时、完整区间平均空闲数、完整采集覆盖率。选择多台机器时，全部空闲时长指这些机器同时全部空闲。
- 时段表提供数量、开始结束时间和未知原因，便于核对。

这里统计的是设备或 NPU 逻辑芯片，不擅自换算物理卡。空闲指没有可见计算进程、利用率明确为 0、健康状态非 Alarm；不筛选显存，也不保证 CPU、存储或网络空闲。GPU 与 NPU 分开查看。

设备小时按空闲设备数乘时间累加。有未知时它只是已确认值的下界。平均空闲数仅在设备状态完整的区间按时间加权，不能用少数采样点代表全天。

## 未知与数据保留

历史从升级后首次采集开始记录，不会把旧变化事件补成数量曲线。首次采样前、采集失败、样本过期、重启中断、写入缺口等时段单独保留为未知。今天尚未来到的时间留白，不计入覆盖率分母。

样本有效期包含采集本身的耗时。后台停止期间不会凭空积累空闲时长；电脑休眠、异常退出等无法精确确认原因时显示采样间断。观察是周期采样，两次采样之间的短暂变化可能未被发现。

默认保留 30 天，后台分批清理。同样的原始设备字段可无损合并，但每次采样的时间证据保留；字段变化频繁时存储仍会增长。大范围或高变化查询超过保护限额时会明确提示缩小范围，不会返回假装完整的截断统计。

按集群查看历史使用当前成员，包含机器加入集群前属于该机器的历史。时区使用 IANA 名称，按自然日边界计算，包括夏令时的 23/25 小时日。

首版提供单日查看。CSV 导出、保留期设置、较长周期概览及 AI/MCP 历史工具属于后续增强，当前没有入口。

绘图默认合并前后空闲数量一致、设备身份和后台运行未改变的短暂断连（最多2分钟）。合并块用 `*` 标记，悬浮显示累计中断秒数；可取消勾选查看原样。只影响热力图和单机图的外观，统计、预约和原始时段表仍保留未知。长时间中断、重启、设备更换和前后数量不同不会跨越合并。

时间范围默认最近1小时，也可选最近3/6小时、全天或指定日期内的起止时间。图表、热力图、时段表及统计都按同一范围计算。当天的快捷时段截至现在，过去日期截至当日结束；时间按所选IANA时区解释。
