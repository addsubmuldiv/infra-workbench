## 发现并修正

| 优先级 | 问题 | 修正与验证 |
|---|---|---|
| P2 | Excel 导入 HTTP 流式入口按实际配置拒绝，但错误仍声称 2 MiB | 使用实际 `MAX_FILE` 格式化提示；在裸 FastAPI 测试中将上限设为 8 字节，验证 9 字节请求返回真实 413 信息 |
| P2 | 技能导入 HTTP 流式入口仍声称 2 MiB | 使用实际 `UPLOAD_LIMIT`，同样验证实际 HTTP 413 信息 |
| P2 | 日志解析单行超限仍声称 64 KiB | 使用实际 `MAX_LINE`，4 字节小上限回归 |
| P2 | 日志记录数超限仍声称 10,000 条 | 使用实际 `max_records`，保留默认千分位格式，1 条上限回归 |

同时将对应错误翻译接到 Excel、技能和日志对比的真实 API 客户端，避免仅有翻译模板而调用路径直接显示中文。前端回归直接模拟服务端 413，验证英文真实上限。

SSH 复核确认：原生 OpenSSH 监控的 8 秒和跳板子进程的 20 秒预算在基线已独立存在；配置中的连接预算只替换 AsyncSSH 无显式设置时的回退值。本轮澄清中文注释，没有合并这些数值或改变既有优先级。

未发现其他可确认的权限、取消、默认值或交付一致性缺陷。后端修正经独立复核，相关 7 项通过；前端修正经独立复核，相关 11 项通过。构建审查核对了最后冻结路径修复及 14 项探针一致性检查。
