# 训练精度对比

功能分支：`feature/log-precision-compare`。入口：左侧「精度对比」，也支持页面地址后加 `#precision`。

## 使用

1. 在基准 A 和待验证 B 中，分别选择已添加的机器，填写远端日志文件的完整路径。可以同机，也可以不同机器；支持 `~/...`、中文、空格路径。目录按钮可浏览远端文件。
2. 点击「读取并对比」。自动识别逐行 JSON（允许时间戳、rank 前缀），支持 `iteration: "1/300"`、整数 iteration、global_step 或 step。默认指标是 loss 和 grad_norm，其他数值字段可勾选，最多 8 个。
3. 查看提取预览。如果检测到多个 rank 或 step 回退形成的训练段，先选择双方轨迹，再点「计算误差」。重复 step 默认拒绝合并，可明确选择首条或末条。
4. 按真实共同 step 计算平均绝对误差、最大绝对误差及对应步数。缺失步数、指标缺失、非有限值和学习率不一致会展示。未出现共同有效数据时，不会以零误差代替。
5. 点击曲线定位 step，点击误差表中的行号查看双方对应原文。单行原文展示上限 800 字符。CSV 导出所有已选指标的全部有效配对，不仅是表格中前 200 行。
6. 输入名称保存配置，记录双方机器和路径、指标、轨迹、范围及重复策略。浏览器还会记住未保存的表单；重开页面后重新读取日志即可。
7. 双方日志路径下各有「下载原始日志」按钮。选择机器、填写路径后即可下载，不必先解析或计算。文件名带基准/待验证标记和机器名，保留原始字节、换行、非 JSON 输出及完整行；不受指标选择、step 范围、提取记录数或原文预览长度影响。

## 计算规则

每个指标分别对共同 step 中双方都有有限数值的记录计算：

`MAE = sum(abs(candidate[step] - baseline[step])) / count`

有符号差值采用 `B - A`。不按行序号对齐，不插值、不平滑，不把缺失值填成 0。曲线最多抽样约 1500 点以保证绘制速度；摘要及 CSV 始终使用全部配对。并列最大误差展示最早的 step。learning_rate 一致仅作辅助核对，不能据此断言两次训练配置完全一致。

## 访问与上限

- 复用现有 SSH 配置、公钥或当前密码会话。只执行固定 Python 读文件脚本；路径通过标准输入作为数据传递，不拼接 shell 命令，不安装远端程序、不使用 sudo。
- 默认 UTF-8 日志。每份文件最多 64 MiB、10,000 条有效指标记录、每行 64 KiB；超限明确报错，不计算部分日志的 MAE。只读取开始时的文件长度，后续追加的内容在下次读取时获得；读取时截断或同尺寸改写会报错。
- 每次读取产生独立快照，保留约 30 分钟，最多 8 份。过期、被淘汰或服务重启后要求重新读取。原文及指标快照仅在进程内存中，SQLite 只保存对比配置。
- 目录浏览最多扫描 5000 个条目，展示前 500 项。权限不足或路径不存在会明确提示。
- 「载入示例」使用用户提供的数值和人为偏移的对照数值，明确标为示例，不连接实际服务器。
- 原始日志下载与解析限制分开：每份最多 512 MiB、传输超时 5 分钟。下载读取开始时的完整文件长度；正在写入的日志后续新增内容不包含在这次文件中，因此下载内容可能比先前对比快照更新。后端先校验收齐文件再开始浏览器下载，截断、断连或权限错误不会伪装为成功文件。临时文件在完成或取消后删除。
