## 新电脑验收

1. 使用 Windows x64 电脑运行 NSIS `-setup.exe`。这是开发测试包，无 Authenticode 签名，不作为正式自动更新包分发。
2. 新电脑无需 Python、Node.js、Rust；远程交互仍需要 Windows OpenSSH，可用 `ssh -V` 检查。WebView2 按安装器提示处理。
3. 首次打开应是空工作空间；确认主窗口、托盘、资源浮窗和新手引导可见，无源码路径或模块缺失错误。
4. 关闭再打开主窗口、从托盘重新打开，检查单实例与窗口恢复；退出托盘后再次启动，检查后台能正常退出/重启。
5. 切换中英文及主题，打开独立终端/文件窗口；只需在测试电脑填写自己的 SSH 配置与凭据，不复制开发机 data。
6. 连接测试服务器后检查资源状态；断开连接后不能显示为“零占用/空闲”。验证小文件读写、复制、单文件和文件夹上传下载及取消。
7. 使用脱敏 Excel 测试批量导入，使用自建无敏感信息技能包测试导入；需要模型时再配置自己的接口，确认模型容量查询与切换正常。
8. 检查资源历史、通知、刷新间隔及重启后偏好恢复。不要在测试包验收中安装线上自动更新，否则程序可能被替换为公开版本。
