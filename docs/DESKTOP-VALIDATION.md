# 桌面版验证记录（2026-10-31）

分支：`desktop-entry`。本记录区分 Windows 实际验证、模拟接口验证和未完成的跨平台验收。

## 性能测量

同一套界面，1440×900 内容视口，48 台模拟机器、每台 8 个设备。全部 API 在测试浏览器/WebView 中拦截，测试不向真实服务器发送修改请求。侧栏按同一路径往返拖动。

| 场景 | 拖动帧间隔 P95 | 最大帧间隔 | 超过 50ms 的主线程长任务 |
|---|---:|---:|---:|
| 优化前，Chromium 浏览器 | 83.5ms | 133.3ms | 191 |
| 优化后，Chromium 浏览器 | 16.7ms | 33.3ms | 0 |
| 优化后，Windows 正式构建 / WebView2 | 16.7ms | 33.5ms | 0 |

静置刷新场景三次均未测到长任务。这里是单机、单次场景测量，不能据此承诺所有机器、所有操作或 macOS 都有同样性能，也不能把桌面外壳本身当作改善原因。主要变化是让屏幕外机器卡片暂缓布局和绘制。

`scripts/measure-ui.cjs` 可由 Playwright CLI 加载，也可作为 CommonJS 模块传入一个 Playwright Page。`?perf-cull` 查询参数仅被测试脚本识别，用于试验候选 CSS；生产页面不读取这个参数。

## Windows 已验证

- Debug 和优化后的 Release 桌面外壳均编译成功；NSIS 安装包已生成。
- Release 桌面窗口实际加载工作台，复用原有后台；没有新增第二个监听 8765 的服务。
- 重复启动只保留一个桌面进程/窗口。
- 480、800、1440 像素视口下无页面横向溢出；可滚动到最后一台模拟机器。
- 原生保存对话框能够保存 Blob 下载；检查落盘文本与下载内容完全一致。
- 在实际 WebView2 中，用模拟 API 验证了 CodeMirror 编辑、快捷键保存，以及 20 字节文件上传。
- 在实际 WebView2 中，用模拟 WebSocket 验证了终端键盘输入、回显和 ACK。该项不代表连通了真实 SSH 服务器。
- 实际编辑器有未保存内容时，点击系统标题栏关闭按钮会确认；取消后窗口和编辑内容都保留。确认后桌面进程退出，原后台进程继续运行。
- 打包后的 Python 可执行文件通过独立自检：临时 API 服务、前端 HTML/CSS/JS、平台入口导入和真实本机 ConPTY 输出。使用临时数据目录和随机端口，不读取用户机器配置。

`scripts/check-desktop-flows.cjs` 提供编辑/上传/终端的模拟流程。原生保存、系统标题栏关闭和后台进程状态需要额外的桌面操作与进程检查。
