# 系统托盘与后台监控

日常使用双击根目录的 **`运行.cmd`**，安装完成后工作台会在 Windows 系统托盘中运行。`background.cmd` 也可用于后台启动。首次运行会检查并安装项目运行环境，不需要额外安装托盘库，也不需要管理员权限。

## 托盘菜单

在任务栏右下角寻找薄荷绿色的芯片图标；看不到时点击隐藏图标箭头。悬停提示为「Infra Workbench · 后台监控」。右键打开菜单，双击图标打开工作台。

- **打开工作台**：在默认浏览器打开本地页面。
- **桌面通知**：默认开启；可关闭，偏好保存在本机 `data/desktop.json`。关闭期间事件仍记录在工作台中，重新开启不补发历史通知。
- **登录 Windows 时启动**：默认关闭。勾选后只修改当前 Windows 用户的启动项；取消勾选删除本程序的启动项。登录后在后台启动，不自动打开浏览器。
- **发送测试通知**：向 Windows 发送一条测试提醒，不修改规则或远端资源。
- **退出托盘并停止后台监控**：如果服务由本托盘启动，退出时一并停止。若接入的是原来已经运行的服务，菜单会显示「退出托盘（已有服务继续运行）」，此时只退出托盘，绝不停止其他服务。

## 浏览器关闭后

先在工作台的设备表勾选设备，添加「监控所选」规则。后端持续采集并记录规则变化，托盘每两秒读取新事件，然后发送 Windows 桌面通知。无需保持网页，也不需要浏览器的通知权限。

「卡预约」也由后台持续处理：预约条件连续满足设定时间后发送一次提醒。默认使用 Windows 通知；只有在这条预约中勾选「使用邮箱通知」，且邮箱配置可用时，才额外发邮件。关闭网页不影响预约和邮件发送，退出后台则暂停观察。详见 [卡预约](RESERVATIONS.md) 和 [邮件通知](MAIL.md)。

托盘启动时接收启动期间的新事件，以及最近两分钟内尚未处理的预约提醒。已提交或发送结果待确认的预约不会重复发送，过期提醒不再补发。待发预约单独排队，不会因为最近事件列表变长而丢失。一次出现多条变化会合并为一条提醒，完整记录仍在工作台中。

点击单条预约通知可打开对应机器，并选中提醒时满足条件的设备。合并提醒或系统无法区分多条气泡时，会先打开「卡预约」，再点击对应记录的「查看机器和设备」。预约列表分别显示条件是否满足，以及 Windows、邮件的发送状态；「已提交 Windows 通知」表示系统接受请求，不代表通知已显示或已阅读。状态说明见 [卡预约](RESERVATIONS.md#如何看通知状态)。

SSH 断开、重连，以及采集或本地服务失败、恢复均不发送系统通知，只在页面显示连接状态；资源占用变化和释放提醒继续保留。浏览器通知也会过滤连接变化和过期事件。

电脑关机、睡眠、网络断开时不能持续采集。远端仅密码登录的会话在服务重启后仍需重新连接；推荐使用已有 SSH 免密配置。sudo 设置继续按每台机器原有规则处理。

如果同时开启网页里的「浏览器通知」，网页开着时可能收到两种通知。使用托盘提醒时可不启用网页通知。Windows「请勿打扰」、通知禁用或系统策略可能抑制提示，先用托盘菜单的测试通知检查。

## 与现有控制台服务共存

后台启动会先检查本地服务。已有工作台服务时直接接入，不重启、不修改 SSH 会话；原来运行服务的窗口仍需保留。如果关闭那个窗口，页面会显示服务断开，托盘不会反复弹通知。希望完全脱离控制台运行时，先自行结束旧服务，再运行 background.cmd；托盘自己启动的服务不需要控制台窗口。

重复运行 background.cmd 只打开工作台，不会增加第二个托盘图标或第二套通知。

## 开机启动与卸载

开机启动实际上是「当前用户登录 Windows 时启动」。使用 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 下的 `InfraWorkbench` 条目，不创建计划任务或系统服务，不修改其他启动项。路径使用当前 Python 的 pythonw.exe 和后台脚本的绝对路径，不带任何账号密码。

移动、升级到另一目录或删除项目之前，先从旧版本托盘取消开机启动。新目录安装后可重新勾选。直接删除项目不会自动清除启动项，也不会清除 Windows 凭据管理器里的 sudo 密码。

托盘错误日志保存在 `data/desktop.log`，最多保留两份各约 256 KB。运行后台入口后没有图标时，用 start.cmd 检查服务能否启动，并检查此日志。

通知使用独立的 `InfraWorkbench.Desktop` 应用身份，显示名称和图标取自工作台本身。首次启动会注册当前用户的 `HKCU\Software\Classes\AppUserModelId\InfraWorkbench.Desktop`，并建立「开始菜单 → Infra Workbench」应用快捷方式，绑定相同的 AppUserModelID，让 Windows 能解析友好名称与图标。不会修改 Python 或其他程序的身份，也不会因此启用开机启动。更新前已经显示的旧通知不会被改写；退出旧托盘并重新运行 background.cmd 后，新通知使用新身份。卸载时可一并删除这份开始菜单快捷方式。
