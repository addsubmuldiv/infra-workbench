# 助手消息的 Markdown

助手回复支持标题、粗体、斜体、删除线、嵌套列表、引用、分隔线、链接、图片、表格、任务列表和脚注。标注语言的代码块支持语法高亮；未识别的语言仍按普通代码显示。

数学公式使用 KaTeX 渲染，字体随应用打包，无需访问外部 CDN。

行内公式：

```markdown
能量为 $E=mc^2$。
```

独立公式（分隔符各占一行）：

```markdown
$$
\operatorname{Attention}(Q,K,V)
=\operatorname{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V
$$
```

可使用分数、上下标、根号、求和、积分、矩阵等 KaTeX 支持的 LaTeX 数学语法，不支持任意 LaTeX 包。长独立公式和表格可以横向滚动。代码里的公式分隔符保持原样；正文中需要美元符号时可写 `\$`。

公式随流式回复更新；尚未闭合或语法错误的公式可能暂时显示为原文或错误标记，不会中断整条回复。

同时支持 LaTeX 常见分隔符：行内 `\(...\)`，独立公式 `\[...\]`。独立公式的起始分隔符应位于新段落的开头；可以写在一行，也可以分多行。`math` 代码块也可直接渲染数学公式。

Mermaid 图表使用标注为 `mermaid` 的代码块，例如：

````markdown
```mermaid
flowchart LR
  A[用户输入] --> B[Agent 助手]
  B --> C[调用工具]
  C --> D[生成回复]
```
````

图表由 Mermaid 官方库在本地按需绘制，支持该库的流程图、时序图、类图、状态图、甘特图等语法。图表保留可展开的源码；未完成或语法有误时显示提示。流式输出稍作停顿后更新图表。大图可横向滚动，单张图表源码限制为 50,000 字符。

Mermaid 使用严格安全模式，绘制结果经过 DOMPurify 清理，不启用图表中的点击回调。消息中的原始 HTML 不执行。LaTeX 支持范围仍是 KaTeX 数学排版，不包含完整 `.tex` 文档编译、任意宏包或 TikZ 绘图。

验证：在 `frontend` 目录执行 `npm test` 和 `npm run build`。
