# 集群操作

集群把同一组机器放在一起，不修改它们已有的 SSH 配置。每台机器最多属于一个集群；删除集群后，机器回到“未分组”。

## 归类与导入

在机器列表中新建集群，再从菜单管理成员，或勾选机器后移动到目标集群。搜索同时查找机器和集群名称。集群复选框选择当前筛选匹配的成员；菜单中的集群操作会再次列出本次目标。

Excel 导入预览中可以选择目标集群。新增成功的机器自动归类；已有机器仅补存密码时保留原归属。

## 打开终端与广播

集群菜单可以批量创建专用持久终端会话。每台机器有独立终端，关闭界面不结束远端会话。连接失败的机器单独显示错误。

广播发送一条完整的单行命令。为避免把命令发进正在操作的程序，已连接的交互终端、忙碌会话和无法核实 Shell 状态的会话会跳过。广播只报告发送情况，不代表命令执行成功。发送结果不明时先检查机器，不要立即重复发送。

## 批量命令任务

需要输出、退出码和可追踪状态时，使用“执行命令”。确认目标列表，填写命令，可指定绝对工作目录、超时及 sudo。默认以普通用户执行，超时 300 秒、并发 5 台。命令在独立远端任务中运行，不会注入正在使用的交互终端。

一台失败不会阻止其他机器。关闭页面或后台重启不自动停止远端任务；重启后尚未启动的机器暂停，需主动继续。取消会停止待派发项并向已运行任务请求停止，最终状态需等待确认，已经发生的文件修改不会回滚。

失败项可主动重试，但要先判断已发生的副作用；结果未知时先查询，不能直接再次启动。每个输出流有大小限制；远端临时目录被清理后，输出可能无法恢复。重要训练输出请主动写入长期日志。不要把明文密码或令牌写进命令正文。

## AI 助手与 MCP

内置助手和外部 MCP 共用集群服务，可查询和管理集群、创建持久终端会话、提交批量命令、读取结果及取消任务。工具名称和参数以当前 tools/list 为准。

助手仍受本轮机器范围限制。集群包含范围外成员时，不会自动扩大权限或把部分执行说成整个集群执行。创建会话后如果没有接入的界面，会返回打开入口，不代表客户端已经打开终端。

### 终端广播的首版限制

工作区创建会话后先显示标签，点击“接入交互终端”才连接显示通道。尚未手动接入的专用会话可用于广播；一旦手动接入，该会话会退出广播目标集合。这样可以避免断开终端后残留的半行输入与广播命令拼接。需要继续统一下发命令时，可使用独立批量命令任务，或新建一批专用终端会话。工作区中的连接说明会明确提示此行为。
