# Python desktop GPU float implementation plan

Goal: One lightweight Tkinter floating monitor with compact, fleet and single-host views, opacity 30–100%, hover readability, pinning and persistent placement.
Architecture: Reuse cached /api/state, never trigger SSH collection. One worker performs bounded local HTTP reads; Tk main thread draws only changed data. Windows singleton, launch from toolbar and tray. Existing Tauri and backend remain intact.
