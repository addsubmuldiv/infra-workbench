# Excel 批量导入服务器实施计划

> 使用 executing-plans 在当前会话逐项实现，完成后统一复查。

**Goal:** 从 Excel 导入多台服务器，展示实时进度、成功数量和失败明细，并可在导入完成后后台配置免密。

**Architecture:** 后端在内存中解析并暂存 `.xlsx`，返回不含密码的预览。异步任务复用单机连接逻辑；登录成功即添加机器，免密配置使用独立 SSH 会话，随后单独排队执行。前端轮询两个阶段的进度，支持下载不含密码的结果表。

**Tech Stack:** FastAPI / asyncio / openpyxl + defusedxml / React + TypeScript。

**Spec:** 用户本次要求：IP、账号、密码表批量导入；汇总成功和失败及原因；导入进度条；可选后台免密，不能阻塞导入成功报告。

## 约束
- 仅连接确认成功后添加；已有机器独立验证并补存 SSH 密码，保留原配置；表内重复目标跳过。
- 不保存上传文件；密码不进入预览、结果、导出、日志或数据库，过期和任务完成后释放。
- 不自动信任主机指纹，不开启 sudo；用户提供的 Excel SSH 密码验证后保存到系统凭据管理器。
- 首个工作表、首行表头；支持中英文列名；端口默认 22；最多 100 台、2 MiB。
- 免密使用独立 SSH 会话，不关闭刚导入机器正在使用的监控或终端会话。

## 验证记录
使用隔离服务和模拟 SSH，从真实浏览器上传测试 Excel：7 行得到导入成功 3、失败 2、跳过 2；导入 100% 时免密仍在排队。最终免密有 1 台失败但导入成功数仍为 3；已实际下载不含密码的结果 CSV。独立代码复查后补充并修复：启动请求与关窗竞态、锁内重复判断、带前导零格式的数字密码、低报工作表 dimensions、记录失效停止轮询。

## 复查重点
部分成功继续执行；登录成功与免密成功分别统计；前端关闭后任务继续；重复开始不执行两次；异常文本不回显密码；退出服务回收任务及未使用凭据。

## 已有 SSH 配置机器的批量补存
- 复用现有入口，支持 SSH 别名或解析后的地址、账号和端口匹配；非标准端口需填写。
- IP 匹配多个别名时标记格式错误，提示使用唯一 SSH 别名，不猜测目标。
- 预览绑定 host_id 和连接身份摘要；执行前重查目标、账号、端口与路由，发生变化或机器被删除则要求重新预览。
- 已有机器只通过独立连接验证密码并保存，不替换监控会话、不改密钥/跳板、不重复添加、不执行后台免密。
- 别名/IP 指向同一已有目标的行去重，预览、进度和导出都不包含密码原文。
