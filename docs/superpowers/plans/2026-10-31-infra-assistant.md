# 跨机器查找与资源变化摘要实施方案

目标：复用已保存的 GLM-5.3-Flash 设置，提供不需要配置项目路径的跨机器查找和资源变化摘要。所有模型提示词、示例和输出要求使用中文。

边界：模型理解查询及归纳采样事实，不执行模型生成的命令。程序负责资源条件判断、实际结果匹配、变化检测及引用校验。无历史、离线、过期和权限不足不得算作空闲或没有任务。

- [x] 后端新增 `resource_history.py`：7 天有界采样事件和基线；记录进程出现/消失、设备占用变化、采集失败/恢复，重启或采集间断不推断任务完成。
- [x] `remote_probe.py` 增加当前登录用户和固定只读 tmux 查询；沿用既有 SSH 采集，不安装远端程序。
- [x] 新增 `infra_assistant.py`：中文查询转严格 JSON 条件，程序搜索占卡进程、资源、tmux 和主机；摘要只使用有编号的变化记录，引用必须存在。对模型请求限流、超时和无效 JSON 明确失败，不伪装为无结果。
- [x] `app.py` 接入采样与新接口；保留现有 MCP 边界与旧功能。
- [x] 前端新增「AI 助手」页：查找结果可定位机器/打开终端；资源变化页可选择时间范围、查看原始事实并手动生成摘要。请求中断/失败不清空事实或伪装成功。
- [x] 测试先验证接口缺失，再实现；覆盖模型误输出、过期数据、账号未知、未知进程、离线恢复、重复采样、跨重启及敏感信息边界。
- [x] 用真实 GLM 和人工构造的已知事实评价效果；用现有真实只读资源快照评价查找，分别标注演示数据与真实状态，不为了演示结束进程或制造资源变化。
- [x] 运行后端/前端检查、构建和隔离浏览器验证。现有正式后台不强制重启。原有 Windows SSH 权限用例仍失败，详见效果验证记录。
