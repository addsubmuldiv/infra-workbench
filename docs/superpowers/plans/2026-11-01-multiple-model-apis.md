# 多 API 配置实施计划

**Goal:** 保存多套接口并在助手切换，保留现有 GLM。
**Architecture:** 增加带稳定 ID 的配置集合，独立凭据；现有单接口 API 兼容当前选中项。每轮聊天使用配置和凭据快照。
**Tech Stack:** FastAPI / React / TypeScript。
**Spec:** 本次聊天中用户已批准的方案。

- [x] 后端配置集合、默认项、独立凭据、旧配置迁移；测试重启、删除和同地址不同 key。
- [x] 每轮快照和回复模型记录；验证切换不影响进行中的调用。
- [x] 设置页多配置管理，助手切换菜单；检查未保存编辑、错误反馈。
- [x] 执行后端相关回归、前端测试和构建；核对真实 GLM 配置保留。

约束：不输出密钥、不提交用户现有修改、不修改实际接口地址和模型。


验证结果：后端相关回归 85 passed；前端 227 passed；TypeScript/Vite 构建通过。浏览器验证新增、重命名、保存、默认项、助手切换、跨入口同步及保留未保存编辑。真实 GLM 使用原系统凭据收到 Responses 文本回复，约 2112 ms。DeepSeek 使用合成凭据和本地 HTTP 服务验证路由隔离，未声称真实 DeepSeek 连通。

审查修复：新增配置一次持久化；旧表单保存/删除密钥/测试和陈旧聊天请求校验配置 ID；窗口获得焦点刷新状态。原有 GLM 数据未改写，沿用 legacy/provider 凭据项，首次编辑集合时持久化迁移。
