# 让工作台成为完整 Codex 宿主

状态：用户已批准，核心原生宿主实现与验证完成；扩展及平台限制见实施记录。日期：2026-11-07。

## 用户确认的方向

用户选择“完整 Codex，工作台作为宿主”：内部 Codex 可操作本地项目、运行命令、调用原生子 Agent，同时接入工作台服务器和 Skills。执行循环、上下文管理及子 Agent 交给 Codex，不在 Deep Agents 中重新实现 Codex。保留现有模型接口引擎作为可选入口，不在本次删除或迁移其历史。

## 当前实现与依据

- `backend/codex_agent.py` 经 stdio 启动 App Server，使用 CLI 登录和默认模型、临时目录及只读沙箱，关闭原生 Shell、多 Agent、浏览器等能力；原生审批直接拒绝。
- 工作台技能通过每轮快照和 `list_skills` / `read_skill` 提供；指定技能已写入指令。
- `backend/agent_runtime.py` 的 general-purpose 只存在于 Deep Agents 图，不是 Codex 可调用的 MCP 子 Agent。
- 当前 UI 主要显示回复和工作台 MCP 记录，尚未完整呈现原生命令、文件变更、子 Agent 及阻塞式提问。
- 本机 CLI 实测版本为 0.167.0；已在忽略的 `work/codex-host-protocol` 导出该二进制的实验性协议 schema，包含 cwd、模型、effort、permissions、multiAgentMode 以及审批和提问协议。导出 schema 不等于模型或子 Agent 已验收。

## 产品行为

### 工作目录、模型和会话

Codex 引擎提供显式本机工作目录、CLI 实时模型选择和该模型支持的推理强度；不再固定临时目录和默认模型。无项目时使用应用创建的持久空白工作目录，绝不默认仓库或用户主目录。切换引擎后恢复各自的选项，按共享工作区状态约定保存非敏感偏好。

本机 CLI 继续管理登录及服务连接，不复制 auth 文件，不把工作台模型接口密钥交给 Codex。账号状态仅显示必要的可用性信息。会话绑定工作目录、服务器范围、权限、技能版本及扩展配置的指纹；边界变化时新建原生 thread，保留原审计记录，不继续旧的隐藏上下文。相同边界才恢复 thread。旧版本隔离会话首次升级新建 thread。

### 原生能力

启用当前 CLI 经协议和真实验证支持的原生命令、文件编辑、搜索和原生多 Agent。原生子 Agent 不经过 Deep Agents；界面按父子关系显示任务、状态和结果，并确认其继承权限以及工作台 MCP。若当前 CLI 无法让子 Agent 使用相同范围的 MCP，该项明确不可用，不能绕过范围或伪装成功。

工作台自有 local_* / web_* 与 Codex 原生重复能力在 Codex 目录中去重；服务器、集群、日志、预约和技能工具继续使用共享后端。本轮指定工作台技能先读取，记录实际读取版本。CLI 自身技能通过官方发现机制显示来源，与工作台技能区分；同名时以来源和稳定 ID 区分，不覆盖文件。CLI 自带上下文压缩和执行调度，不加载 Deep Agents 中间件。

完整宿主指对当前支持的 App Server 能力提供真实 UI 和交互，不承诺与 Codex 桌面产品所有私有功能一致。浏览器、电脑控制、插件、图像和其他扩展按 CLI 实际能力探测逐项提供；不支持的显示原因，不通过去掉所有限制冒充支持。对本机全局 MCP、hooks 和插件不静默全量继承；提供可见来源和显式启用入口，之后才纳入该会话配置。不会修改用户全局 Codex 配置。

### 权限与审批

保留按需批准、只读和完全访问，分别映射到当前 CLI 支持的原生策略；以实际协议校验，映射失败不降级放权。只读拒绝原生及工作台变更；按需模式显示命令、cwd、提权原因或文件差异并等待用户；完全访问无需逐项审批，受操作系统权限和 CLI 管理策略约束。UI 说明本机目录是工作上下文，完全访问不是目录沙箱。

原生审批和共享 MCP 审批共用 UI 入口和审计格式，但各自保留协议语义；批准绑定 run、thread、turn、item 和不可变参数。一次批准默认只适用于该请求；CLI 的会话级批准只有用户明确选择才使用，边界变化后废弃。断线不自动批准，取消和后台重启使待审批失效。传输读取不能被待审批阻塞，仍可接收取消、其他事件和并发子 Agent 请求。

工作台机器范围只强制约束工作台 MCP，不能阻止拥有本机 Shell 的 Codex 自行运行 ssh 或访问本机凭据。界面必须明确这点；只读不能等同于禁止所有网络副作用。用户要求完整 Codex，因此采用这一真实边界，不再声称机器勾选限制所有原生命令。工作台 MCP 仍不暴露 SSH 密码工具，所有服务器业务校验保留。

### 交互和记录

呈现原生命令及输出、文件变更及差异、计划、MCP 调用、子 Agent 状态和最终回复；不展示模型私有思维链。原生 item 使用稳定 ID 去重，SSE 重连不会重复记录或执行。输出有界、可分页读取，错误保留可诊断信息并脱敏。

原生结构化提问显示选项或文本输入并等待同一请求的回答，不再先返回空答案再要求下一轮回复。保留 steer、取消和分支，明确分支不回滚文件。原生分支优先使用已验证的官方 fork 路径；不可用时显式以新 thread 和有界同范围历史创建，不冒充完整上下文分支。取消根 turn 要验证子 Agent 清理，远端持久任务继续通过工作台任务工具显式管理。

## 实施范围与顺序

本设计审批覆盖完整宿主主线，按以下依赖顺序实施并逐阶段报告，不以首阶段完成代替整体完成：

1. 当前 CLI 协议适配、能力探测、配置指纹、会话生命周期及审批桥接。
2. 工作目录、模型/推理强度、原生命令与文件差异、结构化提问 UI。
3. 原生子 Agent 的创建/状态/取消呈现，工作台 MCP 和 Skills 的子 Agent 继承实测。
4. CLI 技能发现、可见扩展选择及支持情况；续聊、steer、分支与重连联调。
5. 国际化、独立助手窗口、演示隔离、文档与构建产物，完整验证报告。

尚需实现者决定的细节：组件拆分、事件持久化表结构、输出分页尺寸、协议字段版本检测方式。优先复用现有聊天和审批机制，新增字段保持旧历史可读。不引入新 Agent 框架，不删除 Deep Agents，不改变对外 `/mcp` 默认权限，不更换用户登录或全局配置，不发布安装包或推送代码。

## 验收

- 单元和集成：原生事件去重、并发审批、拒绝与取消、过期请求、重启恢复、配置指纹和范围变化、只读、脱敏；现有 MCP 权限与机器范围回归。
- 使用隔离 IWB_DATA、临时项目和合成服务器工具跑真实 Codex：读写测试文件、命令输出、人工批准/拒绝、技能读取、子 Agent 调用相同合成 MCP、续聊、提问、steer、取消及清理。不读取真实服务器或生产凭据；模型请求产生实际用量。
- 交互只在每轮新建的 Codex 内置浏览器标签页和新建空白聊天验证；原生系统窗口不操作。演示不得调用模型或真实后台。原有工作台运行实例不为验证重启。
- 按项目测试分组运行 assistant、mcp 和受影响的 workspace/files/terminal；若共享认证或广泛基础代码变更则全量回归。前端必须构建并更新 dist，最后 git diff --check。
- 真实模型、CLI 版本、成功能力、失败能力和未验证平台分别报告。Windows 本机结果不代表 macOS 验证完成。

## 主要限制

CLI 协议和可用扩展随版本及账号变化，不能硬编码“完整能力始终可用”。当前 0.167.0 是实现基线，最低支持版本待实现者按实际字段确定，缺失能力必须有明确提示。原生完整访问与工作台的机器范围不是同一个安全边界。所有主张以实际事件、审批和合成工具结果为验收依据。
