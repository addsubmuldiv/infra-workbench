# Windows 部署脚本验证

日期：2026-10-30。测试平台：当前 Windows 开发机，使用 Windows PowerShell 5.1。

已检查脚本语法，实际运行 `install.ps1 -CheckOnly`，确认能发现 Python、OpenSSH 与附带前端，且不会创建正式虚拟环境或启动服务。

`scripts/test-windows.ps1` 在名称包含空格和中文的独立临时目录中运行真实部署脚本。Python/pip 命令使用模拟边界，Git 打包使用真实 Git，覆盖：

- 首次安装失败不写成功标记；已有但安装不完整的环境可重试。
- 健康环境重复安装不重复调用 pip，依赖文件变化会触发安装。
- Repair 主动重跑依赖安装和检查，检查失败会清除旧成功标记。
- 已运行服务直接复用，其他程序占用端口时拒绝启动且不杀进程。
- 原生命令非零退出码正确上报。
- Git 分享包包含安装入口，排除未跟踪的私人数据和虚拟环境。
- 禁止把分享包输出到 release 目录外，禁止未提交修改造成版本不一致。
- 即使误把 data 提交到 Git，也会拒绝生成分享包。

这些检查不代表已在一台没有 Python 的干净 Windows 电脑上完成实机安装。WinGet 下载 Python、首次联网下载 pip 依赖、企业代理与证书环境仍需在接收者环境验证。没有为测试安装系统 Python、改变 SSH 配置、接触真实密码或重启正式服务。
